# 云鹭 · CloudHeron

文档编号：DOC-DEV-004  
版本：v0.1.3

为团队提供图片与视频的对话创作、节点工作流、资产复用与工作流 API。沿用已确认 v0.3.2 云鹭设计。当前为本机首个开发版本。

## 启动

需要 Node.js 24 或更新版本，无 npm 依赖安装步骤。

```sh
cd '/Users/bohan/work/AI漫剧/app'
npm start
```

打开 http://127.0.0.1:8800。首次使用创建团队名称和管理员账号，密码至少十位。没有预置管理员密码。顶栏“手动测试”可载入带编号的示例工作流与对话；载入不运行模型。

## 开始创作

1. 在“模型配置”添加实际服务根地址、上游模型名称、协议、密钥和任务能力。连接测试只检查服务可达；任务能力以实际生成结果为准。
2. 创建项目，设置团队共享或指定成员授权。在成员页创建邀请链接，复制给同事自行设置密码。
3. 上传图片或视频到资产库；角色、场景、道具、风格为图片参考类别。选择固定资产版本进入生成。
4. 对话创作里创建对话，选择图片、视频或提示词 Agent，描述画面并发送。选择文本模型可理解创作历史。
5. 工作流中添加任务节点，连接端口，设置提示词、模型、参考、Skill；保存 JSON 后点击“运行”。AI 助手只分析或给出待确认修改，确认后仍须手动运行。
6. 项目卡片进入对应对话或工作流；生成文件自动进入资产库，可预览与下载。
7. 工作流 API 中发布固定版本，保存仅显示一次的调用密钥，按页面示例提交 prompt 并异步取结果。

## 数据与配置

默认数据：app/data/cloudheron.sqlite、data/media、data/vault.key。密钥文件必须与数据库一同保存，否则已加密模型凭据失去解密条件。备份 SQLite 时应停止服务，或使用数据库在线备份机制，不单独复制活跃 WAL 数据库主文件。data 目录已加入 .gitignore。

环境变量：PORT（默认 8800）、HOST（默认 127.0.0.1）、CLOUDHERON_DATA（默认 app/data）、COOKIE_SECURE=1（HTTPS 部署）。当前本机服务不等同于生产上线；正式部署、HTTPS、备份恢复与多人压力验收在后续阶段执行。

## 实现边界

第一版单团队、单进程、SQLite、本机媒体存储。三个 Agent 配置按任务切换；专家是至少两个 Skill 的有序组合。三个 Agent 配置按任务切换；专家是至少两个 Skill 的有序组合。三个 Agent 配置按任务切换；专家是至少两个 Skill 的有序组合。Skill 为可编辑声明式模板；Agent 为三个内置任务类型。发布 API 输入为 prompt，更多参数 schema、回调、额度与自定义 Agent 安装待后续细化。发布快照固定工作流 JSON 和资产版本，模型服务配置及凭据执行时按 model_id 读取当前值。模型凭据仅管理员配置，执行由服务端代理；具体部署须支持所选任务的接口。参考资产复用不保证人物外观完全一致。没有分镜剪辑、独立一致性检查或运行历史页。

真实模型服务尚未配置：后台与接口契约开发验证已完成，实际图像／视频质量与模型兼容性待联调。模型接口依据和默认规则见 [开发架构](../docs/design/DOC-DES-006-开发实现架构.md)，详细接口见 [接口与工作流契约](../docs/development/DOC-DEV-003-接口与工作流契约.md)，编号与验证见 [开发实施记录](../docs/development/DOC-DEV-002-开发实施记录.md)。

## v0.1.3 项目分组与参考视频

工作流列表和对话历史按项目分组，支持项目筛选。分组内新建默认所属项目；项目页持续显示所有授权项目入口。所有 Agent 可以选择全部 Skill，专家不设置顺序。

视频 Agent 可以选图片或视频参考。参考视频文件需要模型 capabilities 包含 video 和 video_reference。video_format 为 multipart（默认）或 json；reference_fields.image 默认 input_reference，reference_fields.video 默认 video_reference。JSON 用 data URL 传递媒体，multipart 传递真实文件。上游字段和格式以部署服务为准，错误展示在任务结果中。
