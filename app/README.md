# 云鹭 · CloudHeron

文档编号：DOC-DEV-004  
版本：v0.1.6

为团队提供图片与视频的对话创作、节点工作流、资产复用与工作流 API。沿用已确认 v0.3.2 云鹭设计。当前为本机开发版本。

## 启动

需要 Node.js 24 或更新版本，无 npm 依赖安装步骤。

```sh
cd '/Users/bohan/work/AI漫剧/app'
npm start
```

打开 http://127.0.0.1:8800。首次使用创建团队名称和管理员账号，密码至少十位。没有预置管理员密码。顶栏“手动测试”可载入带编号的示例工作流与对话；载入不运行模型。

## 开始创作

1. 在“模型配置”添加实际服务根地址、上游模型名称、协议、密钥和任务能力。连接测试只检查服务可达；任务能力以实际生成结果为准。
2. 创建项目，设置团队共享或指定成员授权。在成员页创建邀请链接，复制给同事自行设置密码。
3. 上传图片或视频到资产库；角色、场景、道具、风格为图片参考类别。选择固定资产版本进入生成。
4. 对话创作里创建对话，选择图片、视频或提示词 Agent，描述画面并发送。选择文本模型可理解创作历史。
5. 工作流中添加任务节点，连接端口，设置提示词、模型、参考、Skill；保存 JSON 后点击“运行”。AI 助手只分析或给出待确认修改，确认后仍须手动运行。
6. 项目卡片进入对应对话或工作流；生成文件自动进入资产库，可预览与下载。
7. 工作流 API 中发布固定版本，保存仅显示一次的调用密钥，按页面示例提交 prompt 并异步取结果。

## 数据与配置

默认数据：app/data/cloudheron.sqlite、data/media、data/vault.key。密钥文件必须与数据库一同保存，否则已加密模型凭据失去解密条件。备份 SQLite 时应停止服务，或使用数据库在线备份机制，不单独复制活跃 WAL 数据库主文件。data 目录已加入 .gitignore。

环境变量：PORT（默认 8800）、HOST（默认 127.0.0.1）、CLOUDHERON_DATA（默认 app/data）、COOKIE_SECURE=1（HTTPS 部署）。当前本机服务不等同于生产上线；正式部署、HTTPS、备份恢复与多人压力验收在后续阶段执行。

## 实现边界

第一版单团队、单进程、SQLite、本机媒体存储。三个 Agent 配置按任务切换；专家组合至少两个不同 Skill，无顺序配置。Skill 为可编辑声明式模板；Agent 为三个内置任务类型。发布 API 输入为 prompt，更多参数 schema、回调、额度与自定义 Agent 安装待后续细化。发布快照固定工作流 JSON 和资产版本，模型服务配置及凭据执行时按 model_id 读取当前值。模型凭据仅管理员配置，执行由服务端代理；具体部署须支持所选任务的接口。参考资产复用不保证人物外观完全一致。没有分镜剪辑、独立一致性检查或运行历史页。

真实模型服务尚未配置：后台与接口契约开发验证已完成，实际图像／视频质量与模型兼容性待联调。模型接口依据和默认规则见 [开发架构](../docs/design/DOC-DES-006-开发实现架构.md)，详细接口见 [接口与工作流契约](../docs/development/DOC-DEV-003-接口与工作流契约.md)，编号与验证见 [开发实施记录](../docs/development/DOC-DEV-002-开发实施记录.md)。

## v0.1.3 项目分组与参考视频

工作流列表和对话历史按项目分组，支持项目筛选。分组内新建默认所属项目；项目页持续显示所有授权项目入口。所有 Agent 可以选择全部 Skill，专家不设置顺序。

视频 Agent 可以选图片或视频参考。参考视频文件需要模型 capabilities 包含 video 和 video_reference。video_format 为 multipart（默认）或 json；reference_fields.image 默认 input_reference，reference_fields.video 默认 video_reference。JSON 用 data URL 传递媒体，multipart 传递真实文件。上游字段和格式以部署服务为准，错误展示在任务结果中。

27 条手动用例见 docs/testing/DOC-TST-002，先回归 TST-003/012/016/021/022/023。原始反馈 8 项通过、2 项失败保留，修复待人工复测。

## v0.1.4 模板与历史版本

工作流列表点击“模板库”，或访问 http://127.0.0.1:8800/#workflow/templates。内置图片、视频和图片转视频模板，使用后创建独立工作流。已保存工作流点击“保存为模板”固定当前 JSON 快照，来源修改不影响模板。默认清空模型和参考资产绑定；选择保留会重新校验引用。

画布点击“版本历史”查看各 revision、时间、操作者和修改来源；“查看与对比”展示历史与当前 JSON。确认“恢复为新版本”生成递增 revision，不覆盖历史，不改变发布 API 快照，也不自动运行。存在未保存修改时先保存，过期恢复请求会被拒绝。旧数据升级只记录当前基线。

本轮新增手动用例 TST-024 至 TST-027；自动回归 31 项通过。实际团队用例已同步为 27 项，用户填写的原始结果保留。

## v0.1.5 任务级 API 参数

生成节点、对话右侧以及工作流 AI 助手新增“API 可选参数”。图片可设置数量、质量、背景和输出格式；视频可设置帧率、宽高比、引导与步数；文本可设置温度、采样、最大 tokens 和停止词。未填写的值不发送；0 和 false 按原值传递。媒体对话的辅助文本参数独立设置。

额外 api_params 支持嵌套 JSON，任务值覆盖模型全局 extra；标准字段使用现有控件，平台模型、提示词和参考文件保持受控。具体字段需模型实际支持；上游不支持会显示真实错误。参数保留在工作流 JSON、模板/版本/API 快照与对话历史中。新增 TST-028 至 TST-032，应用共 36 条手动用例。

完整字段、范围和请求例子见 [DOC-DEV-007](../docs/development/DOC-DEV-007-任务级API参数实施.md)，38 项开发检查通过；真实模型联调仍需接入服务。

## 后端运行与队列

任务队列保存于 SQLite。正常停机完成当前任务、保留排队任务；重启后继续 queued，曾中断的 running 显示失败。`CLOUDHERON_WORKERS` 默认 2，`CLOUDHERON_MAX_PENDING_PER_USER` 默认 10。使用 `sh scripts/start.sh` 启动、`npm run health` 探测。工作流运行、对话提交和发布 API 支持可选 `Idempotency-Key`，同键不同内容返回 409。单数据目录只运行一个服务。

`npm run test:backend` 在隔离环境验证调度、去重、权限、重启与退出。详细接口见 [后端实施](../docs/development/DOC-DEV-008-后端任务与运行管理实施.md)，部署见 [启动与回滚](../docs/release/DOC-REL-002-单机后端启动与回滚.md)。
