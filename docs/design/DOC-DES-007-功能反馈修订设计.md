# 功能反馈修订设计

文档编号：DOC-DES-007  
版本：v0.1.3  
来源：RAW-012;RAW-014

## DES-019 Agent 专属配置面板

关联需求：REQ-033

统一 Agent 能力描述定义字段；图片、视频、文字分别渲染；局部更新右侧，不清空描述。

验收：切换独立参数；隐藏字段不进入该任务请求；历史恢复实际配置。

## DES-020 专家组合与选择

关联需求：REQ-034

三个内置专家；管理员从全部 Skill 选择至少两个 Skill，无顺序配置；对话可选专家及附加 Skill。

验收：后台验证 Skill 存在，合并去重；历史保留专家组合。

## DES-021 手动测试及工作流入口

关联需求：REQ-035;REQ-005;REQ-006;REQ-008;REQ-010;REQ-011

顶栏提供手动测试中心；载入项目与示例；新建同时创建项目；顶部明确导入、导出、AI 修改、手动运行和任务错误。

验收：20 条用例可记录；载入幂等且无生成；工作流错误可直接看到。

图片 Agent：图片模型、理解对话文本模型（选填）、参考图、专家、附加 Skill、分辨率、种子。视频 Agent 增加时长并使用视频模型。提示词 Agent：文本模型、目标用途、提示词专家、附加 Skill，返回文字。

专家至少两个不同 Skill。所有 Agent 可选择全部 Skill，任务标签仅用于说明用途，不限制选择。内部按保存的列表确定性展开模板并去重，用户无需配置顺序；历史保留专家快照。

测试结果当前保存在各账号的当前浏览器，可导出 JSON。业务 SQLite 保存测试项目，Excel 测试表保存正式统筹记录；浏览器结果不会自动写入 Excel。首版生成正向用例需要配置真实模型。

## DES-022 项目分组与持续导航

关联 REQ-036;REQ-027 / DEV-016。工作流使用独立项目分区，对话左侧使用项目与对话分区，均提供全部项目/指定项目筛选。分区中的新建按钮携带项目编号；编辑页返回所属项目列表。项目页导航始终显示全部授权项目。

## DES-023 视频参考选择与模型适配

关联 REQ-037;REQ-015 / DEV-017。图片 Agent 只列图片；视频 Agent 和参考资产节点列图片及视频，显示版本和媒体类型。模型配置增加参考视频能力、视频请求格式及参考字段。没有能力时展示明确错误，不伪装已生效。
