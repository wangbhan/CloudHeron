# DOC-DES-019 生成执行短连接设计

2026-11-11 · DES-043 · REQ-039、046、053 · DEV-030 第一阶段

生成任务在模型等待、媒体下载和 S3 上传期间释放连接。执行器分段读取任务、权限、模型、Skill 和参考资产。节点进度与任务结果分别使用短数据库操作。发布快照、队列领取和进程级执行锁沿用现有机制。

资产先上传，再以数据库事务登记并读取元数据。上传前和登记前校验项目权限。登记失败时删除已上传的对象。对话回复与任务成功状态、批量规划版本与任务成功状态分别在同一事务提交。

验收用例分别阻塞模型响应和对象存储上传，确认任务运行期间连接已回到池中。注入登记失败，核对任务失败、对象清理和数据库无资产行。 [TST-064](../testing/DOC-TST-015-生成执行回归.md)
