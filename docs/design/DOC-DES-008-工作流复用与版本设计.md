## DES-024 模板库与独立复用

关联 REQ-006/007；开发 DEV-018；测试 TST-024/025/027。

工作流列表提供模板库入口。内置图片、视频、图生视频模板，包含明确任务节点、连线及空模型配置。项目模板继承来源项目访问权限，固定保存时的工作流 JSON，不跟随来源草稿变动。已保存流程可保存为模板，模板作为新工作流使用，可选择目标项目。

默认清空 model_id 和 asset_id，保留结构、提示词与 Skill。用户可勾选保留绑定，此时服务端再次校验模型与资产权限。模板复用仅保存新工作流，不调用模型或创建执行任务。查看者可以查看允许的模板，编辑者仅在可编辑项目中创建。

存储 workflow_templates 独立表，模板快照不可变。第一版提供保存、浏览、预览与复用，暂不引入模板覆盖、归档或外部安装。

## DES-025 历史版本与恢复

关联 REQ-006/007/009/010；开发 DEV-019；测试 TST-026/027。

工作流工具栏提供版本历史。列表显示 revision、时间、操作者和来源（创建、手动保存、AI 确认、模板复用、历史恢复、升级基线），支持查看该版完整 JSON，并对比当前保存版。

用户确认一次后，将旧 JSON 保存为新 revision，旧历史保持不变。乐观锁检查当前 revision，其他成员已修改时拒绝恢复。恢复不更改发布 API 快照、不创建任务、不重写产物。查看者可查看允许的历史但不能恢复；未保存修改需先保存。

workflow_versions 独立表以 workflow_id/revision 唯一定位，JSON、操作者、来源、恢复源 revision 和时间在同一事务中保存。升级时仅记录已有工作流当前版本；不回填不存在的旧记录。

## 测试与上线边界

验证零执行副作用、模板快照固定、复制独立、引用权限、版本事务、并发冲突、AI 修改版本、查看者限制和持久化。内置样例不产生预填成功结果。功能在本机更新供手动复测，生产部署继续保持待执行。
