# DOC-DES-018 迈谷风格与项目设定

2026-11-11，DES-042，REQ-046、REQ-052。

工作区从灰阶调整为浅蓝底、白色面板、海军蓝正文和 #1454ed 主按钮。选中导航、状态标签和焦点轮廓沿用蓝色体系。新访客默认浅色，已有主题选择按浏览器设置恢复。深色模式使用蓝黑背景和浅蓝高亮。登录页继续使用云鹭原图，项目页采用浅蓝标题区。

从项目页打开「项目设定」可保存描述、视觉风格和至多 8 个项目资产版本。项目编辑权限用于创建版本，项目读取权限用于查看历史。并发保存时校验基础版本，防止覆盖。对话、批量规划与生成、工作流助手和手动执行均可显式引用文字版本，历史任务读取提交时的快照。参考资产保存在对应版本，选择实际模型输入文件时仍使用各页面的参考文件控件。

视觉参考见[迈谷科技首页](http://156.225.23.164:8900/)。
