# DOC-DES-017 画布AI与批量对话操作设计

2026-11-03；DES-041；REQ-051。

AI修改指令提供schema_version、nodes(params/position)、edges完整结构。格式兼容仅在AI返回结果进入预览前执行：缺失params沿用同ID旧节点参数；AI提供局部params时合并旧参数；缺失坐标沿用原节点，新节点使用网格；二维数组/数字文本转换为x/y，有限越界坐标移入画布范围。所有处理列入修改摘要和JSON差异。坏类型、无效业务参数、模型/资产、端口或环路仍拒绝。普通JSON导入不做自动修复，错误指出节点ID。

批量工作复用原DAG和执行器。run增加card_indices可选0起始索引数组，未填执行全部，空/重复/越界拒绝。编译保持scene_N/generate_N原序号，只执行选中项；快照记录本次索引，界面只展示本次步骤。增删复制与勾选在本地草稿，保存有revision保护。选中上次未完成只改变勾选，用户确认生成才发请求。成功产物留在资产库，详情提供历史产物与下载。

对话创建任务沿用Idempotency-Key：相同内容在未确认受理时复用同键，输入变化新键；已受理后读取失败继续轮询原任务。切换配置不解除运行锁定。失败后恢复上次输入和Agent、模型、Skill/专家及参数；恢复不发送请求，提交才生成。

参考[火宝短剧README](https://github.com/chatfire-AI/huobao-drama)的任务式批量生成、资产管理和任务进度组织；本批不复制代码或素材。云鹭保留FastAPI/PostgreSQL/S3、项目ACL、JSON画板与三种创作入口；输出仍为图片和视频片段。
