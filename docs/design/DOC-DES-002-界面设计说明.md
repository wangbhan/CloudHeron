# 云鹭 · CloudHeron 界面设计说明

文档编号：DOC-DES-002  
版本：v0.3.2  
状态：待评审  
更新日期：2026-10-01

当前处于设计草案评审；需求仍有细节待确认，开发、正式测试及上线尚未开始。32 条需求登记：22 条已确认，9 条细节待确认，1 条已撤销。18 项设计登记：16 项待评审，2 项已废止。

## 本轮变更

- 项目内容按对话创作和工作流分类，点击稳定内容编号进入对应上下文与产物。
- 生成范围收敛为图片与视频，移除分镜剪辑及独立音频、文本生成入口。
- 移除独立运行记录，工作流内仍显示当前进度、产物、错误。
- 一致性检查原指比较同一角色的脸、服装、场景和道具等差异；目前以参考资产选择代替独立页面，自动检测及剧情状态仍待确认。
- 正式名称云鹭 · CloudHeron；登录、侧栏和品牌页面使用标签，品牌风格图由内置 imagegen 生成。

视觉依据保留 [yingma.tv](https://yingma.tv/) 公开登录页的灰阶、细边框、圆角和分区布局；工作台依据本项目需求设计。参考站点登录后的界面未作为依据。

## DES-001 登录与团队接入

关联需求：REQ-001, REQ-016, REQ-031, REQ-032, REQ-026  
状态：待评审  
路由：login

使用云鹭独立产品图标与白鹭云海背景，悬停呈现柔光、雾化和轻微视差，成员通过表单登录。

交互：鼠标悬停光雾与轻微视差；离开背景恢复静态；邮箱密码表单校验与错误反馈；深浅主题下背景、渐隐、文字和表单同步换色。

方案边界：以 RAW-009 用户图片澄清为准；场景与图标以原图局部编辑提取。触屏及减少动态效果模式静态展示，不影响表单输入。 登录背景与表单共享主题底色；悬停光雾按当前主题适配。

截图：[DES-001](../../design/v0.3/screenshots/DES-001.png)。

## v0.3.1 登录视觉细化

RAW-008 / RAW-009 对应 REQ-031 / REQ-032：登录显示白鹭云海场景背景，左上角采用独立透明云鹭图标。背景区有鼠标跟随柔光、局部雾化与约 ±7px 视差，离开恢复；触屏与减少动态效果模式静态展示。色卡、标识变体与卡片边框从登录页移除。此处为设计交互验证，开发、正式测试、上线尚未启动。

## v0.3.2 深浅主题衔接修正

RAW-010 关联 REQ-026 / REQ-031。深色统一底色 #111820，浅色统一底色 #eef3f7；品牌区、表单和背景渐隐层共享颜色，输入框、文字与悬停光雾跟随主题。图像上下边缘渐隐，避免浅色下出现矩形色块。小屏幕同样使用主题底色，触屏保持静态背景。需求总数及阶段不变。
