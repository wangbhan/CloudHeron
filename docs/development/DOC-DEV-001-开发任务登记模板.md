## 登记时机

设计确认后拆分开发任务，定义实施范围、依赖和完成条件。

## 登记字段

- 开发编号
- 关联设计
- 关联需求
- 任务标题
- 实施内容
- 完成条件
- 负责人
- 状态
- 代码定位
- 验证结果
- 版本
- 文档定位

## 条目文档结构

每个条目写明编号、标题、来源、具体内容、完成或验收条件及证据。DOC 定位文档，条目编号定位具体任务；拆分独立文档时另行登记 DOC 编号。文档和 Excel 对应表同步更新。
