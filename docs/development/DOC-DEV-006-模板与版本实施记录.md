## DEV-018 模板库与独立复用

关联 DES-024；REQ-006/007；TST-024/025/027。

内置三个经过 JSON 校验的模板，项目模板保存固定快照与来源 revision。复用可选择已有或新建项目，创建新工作流编号，默认清空模型和参考资产，选择保留时检查可用性及权限。模板列表按项目分组；查看者可预览但不能创建。无模型执行副作用。

代码：app/lib/workflow-library.mjs、app/server.mjs、app/public/app.js、app/public/product.css。

## DEV-019 历史版本与恢复

关联 DES-025；REQ-006/007/009/010；TST-026/027。

创建、手动保存、AI 确认、模板复用和历史恢复在写入工作流的同一事务中留下版本。工作流版本历史提供当前与旧版 JSON 对比；一次确认恢复为新 revision。乐观锁拒绝过期修改；历史与发布快照保持固定。升级仅为既有当前 revision 建立基线，不编造早期修改。测试项目新建流程同样保存首版。

代码：app/lib/database.mjs、app/lib/manual-fixtures.mjs、app/server.mjs、app/public/app.js。
