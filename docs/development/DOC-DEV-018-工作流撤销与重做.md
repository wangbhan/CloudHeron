# DOC-DEV-018 工作流画布撤销与重做

RAW-028 / REQ-055 / DES-045 / DEV-039 / TST-066 / REL-012

## 操作

工作流上方的「撤销」和「重做」支持节点增删、连线增删、一次完整拖拽、应用参数以及整份 JSON 替换。画布快捷键为 Ctrl/⌘+Z 和 Ctrl/⌘+Shift+Z，Windows/Linux 也可用 Ctrl+Y 重做。输入框内保留浏览器自己的文字撤销。

未应用的参数先由「撤销」清除。已经应用的操作按顺序回退，删除节点与删除相关连线记为同一步。撤销后开始新的编辑会清除后续重做记录。

## 保存与历史

DES-045 / DEV-039。当前画布保留最近 50 步。保存时更新版本基线，保留本次打开期间的操作历史。AI 确认修改或恢复历史版本后，可用一次撤销回到操作之前的配置。撤销结果是画布草稿，点击「保存」才写入新版本。生成任务由「手动运行」触发。刷新或离开工作流后，已保存配置通过「版本历史」查看与恢复。

## 验证与发布

TST-066 已加入工作台「手动测试」。使用内置示例工作流可以在没有模型的情况下验证常用编辑。AI 确认场景可在配置文本模型后补测。 [手动验收步骤](../testing/DOC-TST-002-手动测试用例.md#tst-066-工作流画布撤销与重做)

自动验证通过 58 项 Node 用例。隔离 Docker 浏览器验证了节点拖拽、参数、连线、JSON、保存后撤销、AI 提案确认与历史恢复。AI 使用本机测试模型，撤销前后未创建生成任务。
