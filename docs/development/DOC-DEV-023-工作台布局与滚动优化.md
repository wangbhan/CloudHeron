# DOC-DEV-023 工作台布局与滚动优化

2026-11-20 · RAW-034 / REQ-062 / DES-052 / DEV-046 / TST-074～076 / REL-018

## 1. 需求 · REQ-062

现有工作台套框偏多，外层页面和内部区域会同时滚动，长设置挤压创作空间。统一优化项目、对话、工作流、批量创作、模型、资产、成员和测试页面的布局，保持名称、图片、主要导航、业务接口与权限。

验收：聊天输入区不随长列表或消息滚走；内部滚动不带动外层页面；窄屏可打开历史、设置与导航；切换断点不丢参数；工作流所有操作有清晰入口；长表单弹窗不出现双层滚动。

## 2. 审查与设计 · DES-052

参考 design-taste-frontend 的 Redesign - Preserve、先审查、减少无意义卡片、统一色彩和形状、可访问状态与双主题原则。该 skill 主要用于展示页，本次仅采用适合创作工作台的原则，沿用现有原生组件，不引入营销版式或新组件库。DESIGN_VARIANCE=3、MOTION_INTENSITY=2、VISUAL_DENSITY=5。

| 区域 | 原问题 | 调整 |
| --- | --- | --- |
| 对话 | 1828×1050 时文档高度 1179，聊天和设置高度不齐 | 一屏三栏，分隔线替代独立套框；消息、历史、设置各自滚动，输入区固定 |
| 工作流 | 顶栏高 132，十多个按钮横排 | 常用操作保留，导入导出、历史、模板和另存为归入更多；顶栏降至 77 |
| 窄屏 | 列表和设置挤成多层纵向区域 | 对话历史、设置、节点库、参数与执行按需展开；手机导航放入菜单 |
| 批量 | 12 个画面纵排，页面约 5039 高 | 桌面双列，手机单列；生成栏停在顶栏下方，页面约 3285 高 |
| 弹窗 | 长表单外层及正文均可能溢出 | 标题、操作固定，仅正文滚动，扣除边框高度 |
| 列表与资源 | 多层边框、强阴影和重复背景 | 降低容器对比度，实体卡片保留一层，使用自然页面滚动 |

数值来自独立测试样例及对应窗口，内容不同会影响页面长度。滚轮保留浏览器原生行为，不改滚动方向、不接管滚轮事件。内部区域设置 overscroll-behavior，滚动条使用主题适配的细条；画布和宽表格保留合理的横向滚动。

## 3. 开发 · DEV-046

新增 workspace-layout.css，统一维护工作区几何、容器和滚动规则，登录页品牌展示保持原有实现。修正 maigu-theme.css 中共享 :is 选择器意外提升优先级的问题，避免容器和按钮被旧背景覆盖。

新增 features/workspace-layout.js：断点变化时只切换现有面板的 popover 属性，保留同一 DOM、未提交字段和选择；退出浮层模式前先关闭原生浮层。对话三栏在 1280 以上显示，画布侧栏在 1100 以上显示，手机导航在 760 以下展开。面板使用原生浮层及关闭行为。

工作流更多菜单复用原 data-action。AI、节点选择、新增节点和执行结果在窄屏打开参数面板；切换标签时维持面板展开。JSON、版本和模板等控件名称与接口保持一致。顶部主操作不再被旧的 column + wrap 布局挤出视口。

主要页面单一文档滚动，长对话的外层文档保持一屏；聊天与配置使用独立、有边界的滚动区域。设置面板标题保持可见，展开 API 参数后关闭按钮仍可访问。批量画面为真实实体卡片，外层阶段改成留白和分隔线。

## 4. 测试 · TST-074～076

65 项 Node 测试通过，新增跨断点草稿保留和浮层关闭顺序两条回归。既有对话去重、参数、文档确认、工作流撤销等回归保持通过。后端业务代码未修改，本轮未重新运行后端全套测试。

浏览器使用独立 cloudheron-document-qa 环境，准备 25 个对话、13 条长消息、12 个画面及多个模型卡片，不调用生产模型。通过：
- 消息滚轮实际滚动 778 像素，窗口 scrollY 保持 0，输入区保持在工作区底部。
- 390×844 设置面板展开高级参数后内部滚动 1203 像素，外层文档仍高 844；切回 1366×900 保留分辨率和额外 JSON 草稿。
- 手机 AI 面板、结果标签、更多中的 JSON、版本历史、新增节点与撤销；各主按钮完整在视口内。
- 项目、批量、模型、资产、Skill、成员、API、测试共八类列表在手机无整页横向溢出。
- 模型长表单弹窗外层 scrollHeight 与 clientHeight 差为 0，正文可滚；底部操作位于视口内。
- 批量长表单滚动后，生成栏 top=64，顶栏 bottom=56，操作不被遮挡。
- 浅色与深色、桌面和手机均有截图。证据目录 .work/layout-qa-20261120。

本轮验证布局及原有控件可达性，未重新验收真实外部模型生成质量。手动用例 TST-074～076 在页面中保留待执行状态，供用户自行记录。
