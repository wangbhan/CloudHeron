# DOC-DEV-022 统一附件入口

2026-11-20 · RAW-033 / REQ-061 / DES-051 / DEV-045 / TST-073 / REL-017

## 1. 需求 · REQ-061

图片、PDF、Word 的上传按钮统一为输入框左下方「+」。用户展开后选择素材类型，保持原云鹭界面的配色与审美。既有图文分析、确认、生成逻辑继续使用。

## 2. 设计 · DES-051

输入描述和发送操作整合在同一个圆角输入区。加号为 36 像素按钮，菜单采用现有主题颜色、边框与线性图标；四个选项为上传图片、上传 PDF、上传 Word、从资产库选择，每项显示类型说明。空状态仅显示输入框与工具栏，已有素材再显示缩略图和文档状态。

菜单使用原生 popover，在空间充足时向上展开。点击外部、Esc、选择选项后关闭；Esc 或选择选项后焦点返回加号，点击外部时保留点击目标焦点。支持方向键、Home、End。窗口变化时重算位置，滚动页面时收起；窄屏菜单限制在视口内。深浅色均使用现有变量，不新增独立色板。

## 3. 开发 · DEV-045

新增 app/public/features/attachment-menu.js，复用现有 chat-reference-upload 与 chat-document-upload。PDF 和 Word 菜单分别设置 .pdf、.docx 筛选，同文件重选会触发上传；真实格式仍由后端校验。

图片与文档上传、生成任务忙碌时禁用附件入口，结束后恢复按钮和隐藏文件输入。查看者不开放上传；提示词 Agent 可选文档，参考图片和资产项提示切换到图片或视频 Agent。保留缩略图移除、资产选择、摘要编辑与确认，确认后仍由用户显式发送生成。

本次不新增业务接口或数据库迁移。前端样式位于 product.css，上传和分析模块仍使用 REQ-058、060 的接口。

## 4. 测试 · TST-073

63 项 Node 回归通过。本轮针对附件交互执行浏览器自动化：菜单四个选项、方向键与 Esc、点击外部关闭、真实文件选择器的 PDF / Word 类型筛选、图片上传与资产库弹窗、Word 图文理解和确认后发送，以及生成期间禁用和完成后恢复。

模型夹具收到确认摘要与参考图片，测试仅证明平台链路，真实模型效果另行验收。视觉检查覆盖浅色、深色及 390 像素窄屏。手动测试页增加 TST-073，同时更新 TST-069、071、072 的新入口步骤，人工状态保留待执行。
