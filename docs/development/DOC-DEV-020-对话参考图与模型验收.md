# DOC-DEV-020 对话参考图与模型验收

## 对话参考图片

在图片或视频对话的创作描述下方，点击「上传参考图片」直接上传，也可以点击「从资产库选择」。上传后显示缩略图和移除按钮，切换 Agent 时分别保存参考选择，历史对话恢复全部参考资产 ID。文件保存在当前对话所属项目中。

每张图片最多 20 MB，支持 PNG、JPEG、WebP 和 GIF。最多选择 8 份参考，官方 vLLM-Omni 视频每次限 1 份。图片模型需启用参考图片编辑能力，后端在创建任务前校验。视频文件可通过资产库选择，需对应模型具备参考视频能力。

## 模型首次验收

模型列表检测遇到 HTTP 502、503、504 时，在原检测总时限内重试一次 GET。认证失败和参数错误直接反馈。列表返回 404/405 时提示该服务未提供列表接口，可核对路径或手动点击「验证生成」。

「验证生成」支持上传参考图片和选择已有图片，并优先采用模型配置的分辨率及视频时长。提交受理状态不明时，使用同一个对话和幂等键再次提交。实际生成请求仍由用户触发，上游故障在任务中显示。

2026-11-20 对现有文本模型的只读列表实测成功。自动测试用模拟服务验证首次暂不可用、列表缺失以及参考文件传输。真实图片、视频效果仍取决于接入模型。

## 手动验收

TST-069。在图片或视频对话上传一张参考图，核对缩略图，移除后从资产库选回。填写描述并发送，检查历史配置中的参考 ID 和生成结果。切换 Agent 后返回，检查参考选择恢复。不支持参考图的模型应在提交时给出提示。

TST-070。在模型页检测列表，检查持续反馈。使用「验证生成」，选择图片或视频，上传参考图，确认进入对应验收对话，等待任务终态。使用不提供目录接口的测试服务，检查提示与实际生成验收入口。

## 测试与发布

91 项 Python、59 项 Node 通过，覆盖首次列表请求临时失败、目录缺失、参考能力预检、文件传输和验证生成的提交去重。发布前备份 Docker 业务库。无需数据库迁移，重建前后端镜像后加载。

浏览器实测已通过对话上传、资产库选择、图片和视频发送、Agent 参考草稿恢复及带图模型验证。独立模型服务确认三次调用均收到 936549 字节的参考文件，分别进入图片编辑接口和两次视频接口；首次目录 503 后的检测只发出两次 GET。
