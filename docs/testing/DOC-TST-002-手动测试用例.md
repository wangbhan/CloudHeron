2. 点击“验证生成”，选择文本能力与保存项目，提交最小测试描述。
3. 进入自动打开的验收对话，查看实际任务结果；上游502时核对路径、错误和凭据脱敏。

预期：列表检测不执行生成；真实验收创建普通项目任务。任务完成才代表该能力验收成功，失败保持失败并给出具体上游错误，原模型配置不被自动替换。

### TST-054 根地址与Responses文本生成协议

关联：REQ-049 / DEV-033。

前置：具备支持Responses或Chat Completions的模型服务及对应请求示例。

2. 使用验证生成或提示词Agent运行；高级text路径覆盖时核对最终路径。
3. Responses模式填写最大输出tokens，核对结果可显示；错误协议应报告错误。

预期：主机根地址默认拼接/v1，已有版本路径不重复拼接，自定义路径优先。Responses发送input/max_output_tokens并读取output文本，模型名保持原样，不在失败后自动切换协议或重复计费请求。

### TST-055 集成创作建项目、AI规划及刷新恢复

2. 选择规划模型及计划画面数，点击AI整理画面。

### TST-056 集成图片与视频生成、部分失败与画板复用

关联：REQ-049;REQ-050 / DEV-033;DEV-034。

前置：已有画面列表及可用图片/视频模型，真实请求使用上游额度。

1. 确认画面后点击生成，检查每个画面的状态及项目产物。
2. 切换视频片段并选择视频模型，填写服务支持的时长和清晰度，再显式运行。

4. 点击另存为画板，检查生成的节点和画面描述，确认保存画板不自动运行。

预期：图片/视频沿同一执行器进入私有资产库；失败停止后续处理，已完成产物仍显示和可下载。另存画板只创建工作流，无额外生成请求；不自动拼接成片。
