# 云鹭 · CloudHeron 需求说明

文档编号：DOC-REQ-001  
版本：v0.2.2
更新日期：2026-10-16
状态：RAW-020 统一8800及后台管理已实现；真实云服务和生产验收继续

平台现阶段供自己的团队使用，共享项目和资产并配置权限。提供节点式工作流与直接对话创作两类入口，当前仅生成图片与视频。已明确部分行为，细节、第一版范围和验收口径继续讨论。

## 工作流行为

节点执行具体任务，工作流以 JSON 文件表达。用户可手动配置，也可与 AI 对话分析或修改。每次修改向用户确认一次；确认后应用本次修改，取消则保留原配置。确认修改不会执行任务，运行由按钮触发，运行失败显示错误。

## 需求条目

“已确认”表示用户明确了该条规则，并不表示需求阶段已完成。“细节待确认”表示功能方向来自原始需求，边界或验收口径仍待讨论。验收讨论点为本轮整理草案，不构成正式测试任务。
