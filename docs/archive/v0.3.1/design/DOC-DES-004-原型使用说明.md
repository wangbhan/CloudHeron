# 云鹭 · CloudHeron 原型使用说明

文档编号：DOC-DES-004  
版本：v0.3.1  
状态：待评审

入口：[交互设计稿](../../design/v0.3/index.html)。可直接在浏览器打开；本机预览地址为 http://127.0.0.1:8767/#projects，依赖本地预览服务运行。

## 推荐评审路径

1. 项目：用对话创作、工作流筛选，点击雨夜城门图片进入指定对话历史；点击沈青参考图进入对应图片工作流。
2. 工作流：右侧查看已有产物，切换 AI 助手分析或修改。修改出现一次批量确认，取消保留原配置，确认仅应用配置。点击运行按钮模拟失败，错误和旧产物在当前页显示。
3. 对话创作：仅选择图片、视频；选择参考资产；输入请求，任务预览后显示示例产物，加入对应历史并可从项目定位。执行前确认为待讨论候选规则。
4. 登录与品牌：登录页查看独立云鹭图标和白鹭云海背景，将鼠标移入画面查看柔光、局部雾化与轻微视差；离开恢复。品牌页仍保留完整风格说明图。
5. 设计目录：按 REQ 或 DES 检索；顶部需求映射可展开方案与假设。

原型使用示例数据，图片为概念素材、视频为静态预览。品牌风格图是本轮实际生成的图片。模型接入、用户权限、上传、发布 API 等演示不连接真实服务。JSON 保存及新增对话示例使用当前浏览器本地存储。界面检查属于设计验证，未建立正式测试任务。
