## RAW-001 平台八项能力

> 现在我想搭建一个AI漫剧平台，我想有这几个功能
> 1. 节点式工作流：类似 ComfyUI，用节点搭建“剧本→分镜→生图→视频→配音→成片”，支持保存、复用和一键执行。
> 2. 开放模型接入：既能用平台模型，也允许用户通过 API 接自己的模型，兼容 OpenAI / vLLM / vLLM-Omni / SGLang 风格接口。
> 3. Agent + Skill：内置编剧、导演、分镜、提示词、配音等 Agent，并支持 Skill 扩展。
> 4. 对话式创作：用户可以直接说“生成一部玄幻漫剧”“把第三镜改成雨夜”，Agent 自动修改工作流并执行。
> 5. 漫剧资产库：统一管理角色、场景、道具、声音、风格、分镜，保证多集内容复用。
> 6. 角色与剧情一致性：保证人物脸、服装、场景、道具、剧情状态在不同镜头和不同集之间保持一致。
> 7. 分镜 + 时间线：支持镜头编辑、关键帧、运镜、对白、配音、字幕、BGM 和最终剪辑成片。
> 8. 工作流 API 化：工作流做好以后，可以直接发布成 API：输入故事 → 自动生成完整漫剧，方便批量生产和第三方系统调用。
