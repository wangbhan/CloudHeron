### DES-004 AI 分析与修改确认

关联需求：REQ-008, REQ-009, REQ-010  
状态：待评审  
目标：在工作流内对话分析或提出修改；修改经过一次批量确认才应用。

## 数据与状态边界

JSON 配置与运行记录分开。配置包含 nodes、edges、params、position，演示 schema_version 0.1 不代表正式契约。运行记录关联配置修订、触发人、节点状态、错误与产物。端口类型、资源 ID、依赖校验和运行快照仍需详细设计。

资产以稳定 ID 和版本被项目、镜头及节点引用；外观参考与剧情状态分开。模型使用权、凭据查看权和配置修改权分别讨论。

工作流 API 是外部主动调用入口，编辑器 AI 仅分析或修改配置。正式发布还需明确认证、输入输出、版本和异步状态。
