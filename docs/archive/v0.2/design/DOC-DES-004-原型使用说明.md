## 查看

双击 design/v0.2/index.html，或访问当前本机预览 http://127.0.0.1:8766/#workflow。适合 1440×1000 桌面评审；较窄屏幕可滚动画布，移动端范围尚未确定。

## 评审路径

1. 查看登录页风格，进入团队项目空间。
2. 查看工作流画布与 JSON，提出第三镜雨夜修改，取消后再重新提出并确认。
3. 确认仍未运行，再点击运行按钮，查看超时错误和节点定位。
4. 查看对话创作、Agent/Skill、资产与一致性设计。
5. 查看分镜时间线、模型、成员权限、工作流 API。
6. 在设计目录搜索 REQ/DES，查看视觉规范与主题预览。

## 原型边界

AI 回复、生成结果、邀请、模型连接、权限保存、发布和导出成片均为本地交互模拟。没有真实身份系统、外部模型请求、消息发送、视频编码或 API 上线。

工作流可保存至本浏览器 localStorage，键为 aicomic-design-workflow；JSON 可真实导入导出。登录使用示例账号即可。矢量素材与一致性检查结果都是示例。
